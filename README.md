# Process Validation System (PVS)

Proyecto integrador para validar la correcta asignación de personal, certificaciones y modelo de línea en las líneas de producción de WNC usando metodología Scrum, Java y Maven.

Este repositorio incluye:
- Proyecto Java con Maven
- Pruebas unitarias con JUnit
- Estructura lista para integración continua (Travis CI)

Integración continua: configurada con Travis CI para ejecutar mvn test.

CI: Verified Travis integration with automatic Maven test execution.
